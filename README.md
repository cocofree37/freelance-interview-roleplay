# フリーランス・複業案件 面談準備アシスト

フリーランス・複業案件の面談前に、①想定される質問と準備事項、②案件に対する提案文の下書きをまとめて作成するツールです。
現在は**課金なし・API不要**のプロトタイプとして動作します(キーワード判定・テンプレートによるルールベース生成)。Cloudflare Workerをデプロイすると、AIが案件内容を読み込んで生成する高精度版に切り替わります。

**アプリはこちら → https://cocofree37.github.io/freelance-interview-roleplay/**

## 構成

- [index.html](index.html) — 案件の募集要項と、応募者の実績・経歴(任意)を入力すると、①想定質問 ②案件提案文を生成する単体HTMLアプリ。GitHub Pagesの公開ページ本体。`WORKER_URL`未設定の間は外部APIを呼ばず、ブラウザ内で完結する(課金なし)。
- [worker/](worker/) — 案件内容(URLの場合は本文を自動取得)と応募者の実績を基に、Claude APIで①想定質問 ②案件提案文を生成するバックエンド(Cloudflare Worker)。デプロイするとAPI利用料が発生する。手順は [worker/README.md](worker/README.md) を参照。
- [PROMPT.md](PROMPT.md) — (参考)AIチャットに読み込ませて模擬面談のロールプレイをしてもらう場合のシステムプロンプト

## 使い方

1. 上記アプリのURL(またはローカルの `index.html`)をブラウザで開く
2. 「案件内容 / URL」に募集要項をコピペする(URLはページ本文を自動取得できないため、テキストを貼り付けてください)
3. 「あなたの実績・経歴」に職務経歴書や実績の概要を貼り付ける(任意。入力するほど②の提案文が具体的になる)
4. 「出力する」を押すと、①想定質問と準備事項、②案件提案文の下書きが表示される(②はボタン一つでコピー可能)

Web制作・デザイン・マーケティング・経理・ライティング・動画編集・エンジニア・事務など、募集要項に含まれるキーワードに応じて①の質問が自動で調整されます。②の提案文は、入力した実績・経歴の内容だけを使ってテンプレートに沿って組み立てられます(事実を創作することはありません)。

より高精度な(案件内容と実績を実際にAIが読み込んで作成する)バージョンが必要になったら、`worker/README.md` の手順でバックエンドをデプロイしてください。

模擬面談形式で実際にAIと練習したい場合は、`PROMPT.md` の内容をAIチャットのシステムプロンプト/カスタムインストラクションとして設定してください。
