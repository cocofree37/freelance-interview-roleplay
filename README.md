# フリーランス・複業案件 面談 事前準備リスト作成

フリーランス・複業案件の面談前に、想定される質問と準備しておくとよいことをまとめるツールです。
現在は**課金なし・API不要**のプロトタイプとして動作します(キーワード判定によるルールベース生成)。

**アプリはこちら → https://cocofree37.github.io/freelance-interview-roleplay/**

## 構成

- [index.html](index.html) — 案件の募集要項を入力すると、想定質問と事前準備リストを生成する単体HTMLアプリ。GitHub Pagesの公開ページ本体。外部APIを呼ばず、ブラウザ内で完結する(課金なし)。
- [worker/](worker/) — (将来の拡張用・未デプロイ)案件内容をClaude APIに渡し、より精度の高い質問を生成するバックエンド(Cloudflare Worker)。デプロイするとAPI利用料が発生する。手順は [worker/README.md](worker/README.md) を参照。
- [PROMPT.md](PROMPT.md) — (参考)AIチャットに読み込ませて模擬面談のロールプレイをしてもらう場合のシステムプロンプト

## 使い方

1. 上記アプリのURL(またはローカルの `index.html`)をブラウザで開く
2. 案件の募集要項をコピペする(URLはページ本文を自動取得できないため、テキストを貼り付けてください)
3. 「想定される質問を出力」を押すと、フェーズごとの想定質問と準備しておくとよいことが表示される

Web制作・デザイン・マーケティング・経理・ライティング・動画編集・エンジニア・事務など、募集要項に含まれるキーワードに応じて質問が自動で調整されます。

より高精度な(案件内容を実際にAIが読み込んで質問を作る)バージョンが必要になったら、`worker/README.md` の手順でバックエンドをデプロイしてください。

模擬面談形式で実際にAIと練習したい場合は、`PROMPT.md` の内容をAIチャットのシステムプロンプト/カスタムインストラクションとして設定してください。
