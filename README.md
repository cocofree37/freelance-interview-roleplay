# フリーランス・複業案件 面談 事前準備リスト作成

フリーランス・複業案件の面談前に、想定される質問と準備しておくとよいことをまとめるツールです。

**アプリはこちら → https://cocofree37.github.io/freelance-interview-roleplay/**

## 構成

- [index.html](index.html) — 案件の募集要項(またはURL)を入力すると、想定質問と事前準備リストを生成する単体HTMLアプリ。GitHub Pagesの公開ページ本体。
- [worker/](worker/) — 案件内容をClaude APIに渡し、案件に沿った質問を生成するバックエンド(Cloudflare Worker)。未デプロイの間はAIを使わない簡易版(キーワード判定)で動作する。デプロイ手順は [worker/README.md](worker/README.md) を参照。
- [PROMPT.md](PROMPT.md) — (参考)AIチャットに読み込ませて模擬面談のロールプレイをしてもらう場合のシステムプロンプト

## 使い方

1. 上記アプリのURL(またはローカルの `index.html`)をブラウザで開く
2. 案件の募集要項をコピペ、または案件URLを貼り付ける
3. 「想定される質問を出力」を押すと、フェーズごとの想定質問と準備しておくとよいことが表示される

`worker/` をデプロイして `index.html` の `WORKER_URL` を設定すると、案件内容(URLの場合は本文を自動取得)をAIが読み込んで、案件に沿った質問を生成するようになります。未設定の間はキーワード判定による簡易版で動作します。

模擬面談形式で実際にAIと練習したい場合は、`PROMPT.md` の内容をAIチャットのシステムプロンプト/カスタムインストラクションとして設定してください。
